## 🔧 Como Configurar

### Passo 1: Configurar Google Apps Script
1. Acesse [script.google.com](https://script.google.com)
2. Crie novo projeto
3. Cole o código do arquivo `google-apps-script-melhorado.js`
4. Salve como "Diagnóstico 360° - Younv"

### Passo 2: Criar Planilha Google Sheets
1. Crie nova planilha no Google Sheets
2. Nomeie como "Diagnósticos 360° - Younv Consultoria"
3. Copie o ID da planilha da URL
4. Substitua no script: `const SHEET_ID = 'SEU_ID_AQUI'`

### Passo 3: Publicar Script
1. No Apps Script: "Implantar" > "Nova implantação"
2. Tipo: "Aplicativo da web"
3. Executar como: "Eu"
4. Acesso: "Qualquer pessoa"
5. Copie a URL gerada

### Passo 4: Configurar Aplicação
1. No arquivo `src/App.jsx`, linha 29:
2. Substitua `GOOGLE_SCRIPT_URL` pela URL do script

### Passo 5: Deploy
1. Execute: `npm run build`
2. Faça deploy no Vercel
